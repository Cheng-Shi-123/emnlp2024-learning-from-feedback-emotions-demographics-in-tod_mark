## Learning from Implicit User Feedback, Emotions and Demographic Information in Task-Oriented and Document-Grounded Dialogues

This repository contains the source code, scripts, and instructions needed for the experiments described in the EMNLP 2024 paper, "Learning from Implicit User Feedback, Emotions and Demographic Information in Task-Oriented and Document-Grounded Dialogues".

### Paper information
- Paper: https://aclanthology.org/2024.findings-emnlp.264/
- Authors: UKP Lab, TU Darmstadt

### Getting Started
Follow these steps to get started with the code:

#### 1. Clone the repository
```bash
git clone https://github.com/UKPLab/emnlp2024-learning-from-feedback-emotions-demographics-in-tod.git
```

#### 2. Set up the environment
- Python version: 3.8 or newer is recommended.
- Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

#### 3. Run experiments
- See `scripts/` and instructions in the paper/documentation for details.
